# TextClassifer3000

An AI model for recognizing article topics on wikipedia (currently only preprocesses data)

How to Run this program:
    1. run the data_collecter.py file and ensure a wikipedia_dataset.csv file has been saved.
    2. run the preprocessor.py file, and look for an X_matrix.pkl, Y_labels.pkl, and tfidf_vectorizer.pkl file to be saved.
    3. run model_trainer to train classification model on the dataset.
